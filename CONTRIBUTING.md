# Contributing

Thanks for your interest in the Appercept AWS SDK samples.

These samples are maintained by Appercept. We're not currently accepting pull
requests, but we welcome:

- **Bug reports** — found something broken? [Open an issue](../../issues/new?template=bug_report.md).
- **Feature requests** — have an idea for a sample or improvement? [Let us know](../../issues/new?template=feature_request.md).
- **Questions** — if something in a sample is unclear, an issue is the best way to reach us.
